# Nationwide Illustrations: the game

A cartoon learning deck that teaches how to build Nationwide illustrations (Protector, Accumulator, Care Matters Together) as a 4 level game with a boss level, quick checks, and a coach who cheers you on.

Live: https://dwightrfm.github.io/nationwide-illustrations/

Arrow keys or click to move. F for full screen. O to see every slide. Tap quiz answers to play.

Training aid only. All numbers are hypothetical illustrations, non-guaranteed unless marked. Not tax advice.
